# CIS Flight Support — muted MJET-inspired color refresh

This is an independent styling interpretation of the understated premium-aviation look at https://mjet.eu/management/. It is **not** a claim that the palette reproduces MJET’s proprietary exact color codes.

## Color palette

- Primary graphite: `#354047` (buttons, active options)
- Deep charcoal: `#20282D` (utility bar, dark sections)
- Champagne: `#836D51` (rules, micro-labels, links and accents)
- Warm ivory: `#F7F7F5` (light section backgrounds)
- Warm stone: `#E0DED8` (borders and separators)
- Body text: `#454B4E`

## Scope

Color-only updates to `assets/site.css` and all HTML pages for cache-busting plus inline appearance colors. CSS geometry, content, functional scripts, aircraft data, route model and the Academy indigo identity are unchanged. Error notices stay distinguishable from ordinary accents.

Deploy the entire ZIP to the GitHub Pages repository root, including the `assets/` folder. Or replace only `assets/site.css` and the 10 HTML pages in the partial ZIP.
