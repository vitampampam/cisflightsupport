# Rich blue color variant

This is an optional alternative to the MJET-inspired graphite version.

- Primary/action blue: `#17466F`
- Dark navy (header/footer): `#10283F`
- Blue hover: `#123B5C`
- Champagne details retained: `#836D51`
- Warm ivory retained: `#F7F7F5`
- CAW Academy purple stays unchanged.

Only CSS color values, the browser theme-color and the stylesheet cache version were changed. Layout, scripts, content, assets, and aircraft data are identical to the prior MJET package, including the dropdown layering repair.
