# Estimator usability improvements (October 2026)

- Calculate now scrolls to a clearly identified **Your flight estimate** result panel; invalid requests scroll to the actionable validation message. The result panel includes **Edit route**. Deep links do not trigger unnecessary auto-scroll.
- Airport autocomplete is now inline immediately beneath its field. The dropdown never covers the typing area or the opposite input. Keyboard selection remains available.
- **Browse by country → city → airport** below From, To, and Via provides a guided alternative to ICAO/IATA codes. Typing a country such as Thailand also offers a guided selection; city and code lookup remain intact.
- Country labels are bundled offline. The existing 5,448-airport snapshot and routing/pricing computation have not been modified.

Estimator results remain indicative and require operator confirmation.
